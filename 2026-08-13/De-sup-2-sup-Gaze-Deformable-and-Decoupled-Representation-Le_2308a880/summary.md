# 论文速读：De²Gaze

## 一句话总结
论文提出了一种轻量级、高精度的**模型感知型（model-aware）3D眼动估计方法 De²Gaze**，通过引入**可变形稀疏注意力机制（DSA）**和**空间解耦网络（SDNet）**，有效避免了局部噪声干扰并解耦了3D眼球模型中不变与可变特征，在 TEyeD 数据集上取得了 SOTA 精度。

## 研究问题与动机

1. **现有方法依赖密集特征（dense features），对局部噪声敏感**：如强光斑点、模糊等会干扰特征提取，且计算复杂度高。
2. **眼球模型与视线方向存在多对一映射的耦合问题**：同一3D眼球模型可以对应多个不同视线方向，眼动特征与模型特征相互纠缠，显著增加了学习难度。
3. **稀疏查询类方法收敛速度慢**：相比密集预测方法，基于查询的方法（如QueryDETR）常面临收敛慢的问题。
4. **模型泛化性不足**：跨被试时的性能下降明显，现有方法难以有效解耦不变特征与可变特征以提升泛化能力。

## 核心贡献（创新点）

1. **提出可变形稀疏注意力（DSA）机制**：通过将可学习的3D眼球模型投影到2D图像平面生成稀疏采样点，自适应地聚焦于关键语义区域，避免局部噪声干扰；与标准密集注意力相比，**仅采样少量关键点而非全图密集区域**。
2. **提出空间解耦网络 SDNet（双分支解码架构）**：将不变特征（如眼球半径、中心位置）与可变特征（如视线方向、瞳孔/虹膜位置）从潜在空间中分离，两分支各自独立优化，避免特征冲突；与单分支方法相比，**解耦后两类特征不再互相干扰**。
3. **构建可微分的3D眼球模型并嵌入端到端训练框架**：利用先验几何约束指导采样点生成，使眼球模型与深度学习框架无缝融合；与传统的非可微眼球拟合方法相比，**支持端到端联合优化**。
4. **提出边缘点投影生成策略（SPG）**：利用3D眼球投影的 pupil/iris 边缘点作为初始参考点，结合 DSA 引导采样，显著加速了收敛并提升了稳定性。

## 方法详解

### 整体框架
输入为近红外近眼视频帧序列 $\mathcal{T} = \{I_1, I_2, \ldots, I_n\}$，模型 $\Phi$ 输出：3D眼球模型 $e^m$、3D视线 $e^g$ 和 2D语义分割 $e^s$，即 $\{e^m, e^g, e^s\} = \Phi(\mathcal{T})$。

### （1）可学习的3D眼球模型
- 不变参数：$E_{inv} = \{r_e, r_{i_x}, r_{i_y}, T\}$（眼球半径、虹膜长短轴半径、眼球中心平移）
- 可变参数：$E_{var} = \{r_{p_{x_n}}, r_{p_{y_n}}, R_n\}$（瞳孔半径、眼球旋转矩阵）
- 视线方向定义为光学轴单位向量：$g = \frac{o_i - o_e}{\|o_i - o_e\|}$

### （2）采样点生成模块（SPG）
- 将3D眼球的 pupil 圆和 iris 盘离散化为点云：
  $$P_p^C = \{(r_{p_x}\rho\cos\theta,\ r_{p_y}\rho\sin\theta,\ -L_p)\mid \rho\in[0,1],\theta\in[0,2\pi]\}$$
  $$P_i^C = \{(r_x\cos\theta,\ r_y\sin\theta,\ -L_p)\mid r_x = r_{p_x}+\rho(r_{i_x}-r_{p_x}),\ r_y = r_{p_y}+\rho(r_{i_y}-r_{p_y})\}$$
- 通过3D-to-2D投影矩阵得到2D边缘点：$P^{2D} = K[R|T]P^C$，**仅使用边缘点 $P(e)$ 作为 DSA 的初始参考点**。

### （3）可变形稀疏注意力（DSA）
在标准可变形注意力公式基础上，参考点由3D模型投影边缘点确定，而非随机初始化：
$$R_{hn} = P(e_n) + \Delta_{hn}$$
$$f_{hn} = W_h \cdot \text{bilinear}(\mathcal{F},\ R_{hn})$$
$$\text{DSA}(Q^{con}, R_{hn}, \mathcal{F}) = \sum_{h=1}^{H} W_h' \sum_{n=1}^{N} A_{hn} \cdot f_{hn}$$
其中 $A_{hn} = \text{Softmax}(\text{Linear}(Q^{con}))$。

### （4）空间解耦网络 SDNet（双分支解码）
- **不变分支**：专注于稳定几何特征（眼睑区域、眼球整体结构），queries 初始位置由3D投影边缘点确定。
- **可变分支**：专注于动态特征（瞳孔运动、视线偏移），queries 独立更新。
- **联合初始化对齐策略**：将第 $k$ 个可变查询 $Q_{var,k}$ 与对应的不变查询 $Q_{inv,k}$ 一一对齐，确保双分支在同一参考点协同解码。
- 解码器每层包含：自注意力 → DSA → FFN，迭代 $n=3$ 次后输出最终结果。

### （5）损失函数
$$\mathcal{L} = w_{\text{edge}}\mathcal{L}_{\text{edge}} + w_{\text{gaze}}\mathcal{L}_{\text{gaze}} + w_{\text{center}}\mathcal{L}_{\text{center}}$$
- $\mathcal{L}_{\text{edge}}$：预测边缘点与 GT 2D边缘点的欧氏距离
- $\mathcal{L}_{\text{gaze}}$：MSE 损失，衡量预测视线与 GT 视线方向差异
- $\mathcal{L}_{\text{center}}$：加权 MSE，监督眼球中心投影位置

## 实验与结果

### 数据集
- **TEyeD**：全球最大的近眼图像数据集，包含 2000万+ 图像、132名被试。训练集约 34.8万张，测试集约 3.6万张（16名被试），跨被试测试集约 1.6万张（12名被试）。
- 时间下采样至 6.25Hz，保证帧间有明显眼动变化。

### 主要结果（TEyeD-subset_A）

| 方法 | 3D gaze (°) ↓ | 2D gaze (°) ↓ | Sem. IoU | Params (M) | FLOPs (G) |
|------|-------------|--------------|---------|-----------|----------|
| Nikola et al. [12] (Sem.+Gaze+Cent.) | 1.21 | 10.39 | 91.4% | 28.56 | 26.44 |
| **De²Gaze (Ours, Gaze only)** | **0.54** | **5.43** | N/A | 14.48 | 13.56 |
| **De²Gaze (Ours, Sem.+Gaze+Cent.)** | **0.96** | **7.6** | **93.4%** | 14.48 | 13.56 |

- **仅用 gaze 标签监督时，3D gaze 误差降低 48%**（vs. 最优 baseline 1.04° → 0.54°）
- **参数量减少近一半**（14.48M vs. 28.56M），计算量也显著更低
- 跨被试测试（subset_B）：3D gaze 误差 2.61°，泛化能力强

### 收敛速度
De²Gaze 在训练早期即达到稳定，**优于纯查询方法（QueryDETR）且超过密集预测方法（TEyeD baseline）**，验证了 DSA 和解耦设计的效率优势。

### 消融实验
- **移除 SDNet（单分支）**：3D gaze 从 0.54° 上升到 1.18°（subset_A, Gaze only）
- **移除可学习3D模型**：3D gaze 从 0.54° 上升到 1.54°
- **移除 SPG 模块**：3D gaze 从 0.54° 上升到 0.98°
- **移除 DSA（改用标准 attention）**：3D gaze 从 0.54° 上升到 1.11°
- **全部组件均有正向贡献**

## 相关工作脉络

1. **Appearance-Based Gaze Estimation**（如 TEyeD [17], NVGaze [22]）：直接使用图像特征学习眼动到视线方向的映射，依赖密集像素区域，对光照噪声敏感；本文方法通过稀疏注意力规避此问题。
2. **Model-Based Gaze Estimation**（如 Swirski [37], Dierkes [10,11]）：基于3D参数化眼球模型拟合，但模型通常**不可微分**，难以端到端训练；本文构建可微分3D眼球模型。
3. **Model-Aware 3D Gaze (Nikola et al. [12])**：预测完整可微3D眼球模型，但未对眼球特征做解耦，不变与可变特征纠缠导致学习困难；本文 SDNet 显式解耦两者。
4. **DETR / QueryDETR 系列**（Carion [4], Liu [30]）：稀疏查询式目标检测框架，收敛慢；本文引入几何先验（SPG）加速收敛。
5. **Deformable DETR / Deformable Attention**（Zhu [49]）：引入可学习偏移量实现稀疏采样；本文将其适配于3D眼球模型投影边缘点，**参考点由3D几何约束生成而非随机**。
6. **TEyeD 数据集合集**（NNGaze, LPW, GIW, ElSe, ExCuSe, PNET）：本文在其子集上验证，证明了方法在多来源数据上的通用性。

## 局限性与未来方向

1. **未建模 kappa 角偏差**：光学轴与视觉轴之间的 kappa 角偏移未被考虑，导致跨被试精度略有下降（Discussion 部分提及）。
2. **过多2D监督反而降低精度**：加入更多2D约束（如眼球中心、瞳孔中心）后，单一被试精度提升但整体泛化性能下降，说明约束强度的平衡仍需探索。
3. **仅适用于近红外近眼视频**：未扩展到远距离或自然场景下的眼动估计。
4. **未考虑多眼球联合建模**：仅建模单侧眼球，实际应用中双眼协同可能提升精度。
5. **未来方向**：引入 kappa 角建模、探索更优的多监督权重配比、扩展至多视角或多模态场景。

## 研究启发与可借鉴点

1. **几何先验引导稀疏采样的设计思路**：将3D模型投影边缘点作为注意力采样参考点，而非随机初始化——这一思路可迁移至其他需要精确定位的3D感知任务（如手部关键点、人脸3D重建）。
2. **不变/可变特征解耦的架构思想**：将稳定几何特征与动态语义特征分离到独立分支——适用于任何存在"静态结构 + 动态变化"要素的视觉任务（如姿态估计中的骨架 vs. 关节运动）。
3. **边缘点投影作为可微分参考的机制**：通过3D-to-2D可微投影生成参考点，使几何约束自然融入端到端训练——可用于任何需要"3D先验 → 2D特征聚合"的任务。
4. **迭代解码（3次）的设计**：与 DETR 类似但结合了几何反馈，每次迭代用更新的3D模型重新生成采样点——可在其他结构化预测任务中借鉴。
5. **仅用稀疏特征达到高密度的精度**：验证了"少而精"的特征采样策略有效性，对计算受限的场景（如端侧部署）有直接参考价值。

## 关键术语表

**Deformable Sparse Attention (DSA)**：一种结合3D模型投影先验与可变形采样的注意力机制，仅在关键边缘点附近进行稀疏采样，减少计算量并抗局部噪声。

**Spatial Decoupling Network (SDNet)**：双分支解码网络，将眼球参数解耦为不变特征分支（几何结构）和可变特征分支（动态视线/瞳孔），各自独立优化。

**Learnable 3D Eyeball Model**：完全可微分的参数化眼球模型，以半径、平移、旋转变为参数，支持端到端梯度传播。

**Sampling Point Generation (SPG) Module**：利用当前估计的3D眼球模型生成边缘点云并投影到2D平面，作为 DSA 采样的初始参考点。

**TEyeD Dataset**：目前最大的近眼图像数据集，包含 2000万+ 图像、3D眼球标注、视线向量和语义分割，由 132 名被试在多种场景中采集。

**Kappa Angle**：人眼光学轴与视觉轴之间的偏差角，未被本文建模，是实际应用中影响眼动精度的重要生理因素。
