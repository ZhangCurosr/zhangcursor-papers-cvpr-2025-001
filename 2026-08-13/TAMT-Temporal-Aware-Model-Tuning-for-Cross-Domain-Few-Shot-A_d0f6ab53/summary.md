# 论文速读：TAMT-Temporal-Aware-Model-Tuning-for-Cross-Domain-Few-Shot-A

## 一句话总结
针对跨域少样本动作识别（CDFSAR）中现有联合训练范式计算冗余、且未能充分挖掘冻结预训练骨干潜力的问题，本文提出解耦范式TAMT，通过源域SSL+SL两阶段预训练后，在目标域仅微调一个轻量层次化时序调优网络（HTTN），以极低参数开销实现跨域特征重校准与高判别力视频表征生成，刷新CDFSAR多项SOTA。

## 研究问题与动机
1. **跨域分布偏移（Domain Gap）显著**：源域与目标域视频数据分布差异大，直接在目标域少样本上推理会导致特征对齐失败、分类性能骤降。
2. **联合训练计算成本过高**：SEEN、CDFSL-V等主流方法采用源域+目标域联合训练，面对“单源多目标”设定需对模型重训B次，在源域庞大、目标域极小的场景下开销不可接受。
3. **冻结骨干潜力未被充分挖掘**：现有方法在微调/推理阶段多直接套用预训练模型或仅微调分类头，缺乏对中间层特征的动态重校准机制，限制跨域适配上限。
4. **全量微调易引发少样本过拟合**：在目标域仅有极少量标注样本时，全参数微调（FFT）极易过拟合；亟需参数高效且能保留源域泛化先验的适配策略。

## 核心贡献（创新点）
1. **首次为CDFSAR引入解耦训练范式**：将模型预训练（源域）与微调适配（目标域）严格分离，单源数据仅需预训练一次即可复用于多个目标域，从根本上消除联合训练的重复计算开销。
2. **提出层次化时序调优网络（HTTN）**：从局部特征重校准与全局统计表征生成双路径协同适配冻结骨干，区别于仅做空间适配或全参微调的既有工作。
3. **设计局部时序感知适配器（TAA）**：在末层L个Transformer块中插入即插即用子模块，通过带降维的时序卷积学习逐帧时序缩放/偏置，参数量仅为FFT的约1/10，兼顾效率与针对性。
4. **提出全局时序矩调优（GTMT）与高效长短时序协方差（ELSTC）**：利用特征一阶均值与二阶协方差构建视频表征，创新性地以分组协方差替代暴力全时序矩阵，以可接受计算代价捕获从短程静态外观到长程运动的多尺度时序依赖。

## 方法详解
- **解耦两阶段训练流程**：阶段一（源域预训练）先采用基于重建的自监督学习（SSL，沿VideoMAE掩码重建思想）捕捉通用时空结构，再在带标签源数据上进行有监督学习（SL，交叉熵）强化语义判别力；阶段二（目标域微调）固定 backbone，仅优化 HTTN 模块的 CE 损失。
- **局部时序感知适配器（TAA）**：给定中间层特征 $\mathbf{F} \in \mathbb{R}^{T \times M \times C}$，经全局平均池化得时序特征 $\widehat{\mathbf{F}}$，分别通过含降维操作的时序卷积生成缩放因子 $\gamma$ 与偏置 $\beta$（公式2-3），再对原始特征进行逐帧重校准：$\mathbf{F}' = \gamma \odot \mathbf{F} \oplus \beta$。模块以 plug-and-play 方式嵌入最后 $L$ 个 Transformer 块，降维比 $\rho=4$，时序卷积核 $k_t=3$。
- **全局时序矩调优（GTMT）**：将视频表征建模为特征时序矩展开 $Z = 1 + \sum_{p=1}^{\infty} \alpha_p M_p$，工程上截断至二阶。一阶矩 $M_1$ 由 GAP 直接得到；二阶矩 $M_2$ 采用 ELSTC 计算：先将序列沿时间轴拆分为 $G$ 组，每组内经 MLP 降维后计算帧间协方差矩阵 $\mathbf{R}_{t,t'}$，捕获从 $\Delta=0$（静态外观）到 $\Delta=T-G$（长程运动）的多元时序相关性，最后经两层卷积聚合为 $C_M \times C_M$ 统计向量，与 $M_1$ 线性投影对齐后拼接输出最终表征 $\mathbf{Z}$。默认 $G=4, \tau=6, C_M=64$。
- **度量学习推理**：采用原型网络范式，查询视频与支持集视频经冻结 backbone + HTTN 提取表征后，以欧氏距离计算相似度 logits，用于训练与 K-shot 推理。

## 实验与结果
- **数据集设置**：源域含 Kinetics-400/100、SSV2、Diving48、UCF-101；目标域含 HMDB51、SSV2、Diving、UCF-101、RareAct。类别严格非重叠，遵循 5-way 1-shot / 5-shot 协议，推理取 10,000 episode 均值。
- **SOTA 对比（5-way 5-shot）**：
  - K-400 源域：TAMT 平均 68.37%，较 CDFSL-V 提升 **+21.13%**
  - K-100 源域：TAMT 平均 57.91%，较 CDFSL-V 提升 **+31.15%**
  - SSV2 / Diving / UCF 作为源域时，平均提升分别为 **+28.02% / +17.92% / +13.11%**
  - 整体相较 SEEN、DMSD、CDFSL-V 等全部已发表 CDFSAR 方法提升 **13%∼31%**
- **效率对比**：相较全量微调（FFT），TAMT 仅消耗 ~0.1× GPU 显存（1.9G vs 17.5G）、~0.1× 可训练参数（2.8M vs 29.9M）、~0.7× 训练时间（7.3h vs 10.6h）；相比联合训练范式训练成本降低近 **5倍**。
- **消融结论**：SSL+SL 联合预训练优于单一 SSL 或 SL；TAA 与 GTMT 各自贡献显著（GTMT 较纯 GAP 平均 +9.17%）；TAA 在 Adapter/SSF/TAM/ST-Adapter 等多类对比中均获最高分；FFT 在后期训练出现验证集性能下降，印证少样本下全参微调易过拟合。

## 相关工作脉络
1. **SEEN [49]**：首创 CDFSAR 联合训练范式，融合监督学习与自监督对比学习缓解域 gap，但需对每个目标域重训且推理仅用最近邻分类器；本文与其本质差异在于**解耦训练**与**冻结骨干的轻量时序适配**。
2. **CDFSL-V [38]**：提出无重叠类别基准的两阶段联合训练+课程学习，仍属 pair-wise 联合范式；本文打破该限制，以单次预训练+目标域微调实现多目标复用。
