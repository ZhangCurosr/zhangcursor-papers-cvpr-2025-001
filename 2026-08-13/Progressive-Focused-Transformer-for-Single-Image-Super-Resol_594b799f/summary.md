# 论文速读：Progressive-Focused-Transformer-for-Single-Image-Super-Resol

## 一句话总结
本文提出渐进式聚焦Transformer（PFT），通过渐进式聚焦注意力（PFA）机制将网络中各层注意力图以Hadamard积方式相连，使模型能够动态过滤无关token并在更深层次聚焦关键特征，从而在使用更大窗口尺寸的同时显著降低计算开销，在单图像超分辨率任务上达到SOTA性能。

## 研究问题与动机
- **当前Transformer SR方法的计算瓶颈**：自注意力机制需要在所有token对之间计算相似性，但大量token与查询token无关，这些不必要的相似计算不仅浪费算力，还会引入噪声干扰。
- **现有稀疏注意力方法的局限**：top-k等稀疏方法仅基于单层相似度进行一次性筛选，无法在多阶段迭代中进一步区分"高度相关"与"轻度相关"token。
- **大窗口与计算开销的矛盾**：扩大感受野能捕捉更多上下文信息，但自注意力的二次复杂度限制了窗口尺寸，现有方法难以在保证效率的前提下有效使用大窗口。
- **注意力图孤立问题**：各层注意力图相互独立，浅层已识别的重要/无关位置信息无法传递到深层进行进一步聚焦。

## 核心贡献（创新点）
1. **提出渐进式聚焦注意力（PFA）机制**：通过将上层注意力图与当前层计算得到的注意力图进行Hadamard积相乘，使持续相关的token获得更高权重，而无关token权重逐级衰减。与现有top-k等单次稀疏化方法不同，PFA支持跨层迭代聚焦，实现更精细的token筛选。
2. **设计基于稀疏矩阵乘法（SMM）的计算加速策略**：利用上层注意力图生成的稀疏索引矩阵，在计算当前层注意力前跳过低权重位置，实现按需计算。这使模型在维持相当计算资源的前提下可使用更大的窗口尺寸（32×32）。
3. **构建完整的渐进式聚焦Transformer（PFT）架构**：将PFA模块系统化嵌入SR网络，配合偏移窗口（shifted window）策略和LePE位置编码，实现高效的高分辨率重建；同时提出PFT-light轻量版本，在参数量和计算量双降的情况下保持领先性能。

## 方法详解
- **渐进式注意力跨层传播**：第l层最终注意力图通过公式更新：A^l = Norm(A^{l-1} ⊙ A_cal^l)，其中A_cal^l为当前层根据标准自注意力计算的相似度图，Norm(·)为行归一化操作。连续乘法使跨层持续高相似的token获得更大权重，无关token权重被逐步抑制。
- **稀疏聚焦注意力（PFA）核心流程**：
  - 使用上层注意力图A^{l-1}生成稀疏索引矩阵I^{l-1}（保留每行Top-K^{l-1}个非零位置）
  - 通过稀疏矩阵乘法（SMM）仅在索引为1的位置计算Q-K相似性：A_sc^l = Softmax(Ψ(Q^l, (K^l)^T, I^{l-1}))
  - 更新注意力图并进行稀疏化：A^l = S_{K^l}(Norm(A_sc^l ⊙ A^{l-1}))，I^l = Sign(A^l)
  - 输出计算同样通过SMM完成：O^l = Ψ(A^l, V^l, I^l)
- **聚焦比例动态衰减**：首层设K^1 = N（全窗口计算），后续层按聚焦比例α递减：K^l = α·K^{l-1}（0<α<1），实验中α=0.5时效果最优。这使浅层保留充分信息，深层逐步聚焦。
- **网络整体架构**：PFT采用与HAT/SwinIR类似的层级结构，替换为标准自注意力块的是PFA块。经典SR版本含6个block，各block内注意力层数为[4,4,4,6,6,6]，通道数240，6个attention head；轻量版PFT-light含5个block，层数[2,4,6,6,6]，通道数52，4个head。窗口大小统一为32×32。
- **计算复杂度分析**：标准自注意力复杂度为O(hwLC² + W²hwLC)，PFA由于K值逐层指数衰减（K^l = W²·α^{l-1}），复杂度降为Σ(4hwC² + 2α^{(l-1)}W²hwC)，当α=0.5时经过4层衰减后计算量仅为原来的6.25%。

## 实验与结果
- **训练设置**：使用DF2K（DIV2K+Flickr2K）训练500K步，AdamW优化器，初始学习率2×10⁻⁴，输入patch 64×64，batch size=32。
- **测试基准**：Set5、Set14、BSD100、Urban100、Manga109，评估×2/×3/×4三种放大倍数，计算开销在1280×640输出分辨率下测量。
- **经典SR结果（Tab. 1）**：PFT在大多数数据集上取得最高PSNR。以×2 Urban100为例，PFT达34.90dB/0.9490，超越ATD（34.70dB/0.9476），同时FLOPs从6.07T降至5.03T（减少17.1%）；×3 Urban100达30.56dB/0.8931，超越ATD的30.36dB/0.8901，FLOPs从2.69T降至2.23T。
- **轻量SR结果（Tab. 2）**：PFT-light在×2 Urban100达33.67dB/0.9411，超越ATD-light（33.27dB）0.40dB，FLOPs 278.3G对比348.6G（减少20.1%）；×4 Urban100达30.56dB/0.8931，超越IPG-Tiny 0.42dB。
- **消融实验结论**：
  - PFA相比Vanilla SA提升显著（Urban100 ×4：26.62dB vs 26.26dB），且FLOPs减少27.69%
  - 聚焦比例α=0.5最优（26.62dB），过大或过小均损害性能
  - 窗口尺寸32×32优于16×16和8×8（Urban100 ×4：26.81dB vs 26.62dB vs 26.40dB）

## 相关工作脉络
1. **SwinIR [22]**：窗口自注意力+移位策略的开创性工作，本文在其基础上引入跨层注意力继承机制，解决窗口内token筛选效率问题。
2. **HAT [6]**：结合通道注意力和窗口注意力，扩大交互范围；本文方法通过PFA的稀疏计算同样实现大窗口高效利用，但无需额外通道注意力模块。
3. **CAT [7]**：使用矩形窗口和轴向移位增强跨窗口交互；本文与CAT均致力于扩大感受野，但CAT依赖增大窗口计算量，PFT通过注意力聚焦在同等计算量下使用更大窗口。
4. **ATD [41]**：引入自适应Token字典突破局部窗口限制；本文定位差异在于不依赖外部字典，而是通过跨层注意力传播实现隐式全局信息整合，计算效率更优。
5. **DRSformer [5]** / **NLSA [28]**：单阶段稀疏注意力方法（top-k选择）；本文PFA的核心区别在于多阶段迭代聚焦，浅层信息可逐层累积强化，而非一次性筛选。
6. **IPG [31]**：利用图神经网络增强像素间关系；本文与之区别在于完全基于注意力机制的token级稀疏化，不引入额外图结构计算。

## 局限性与未来方向
- **首层必须全窗口计算**：第一层注意力无先验信息，需进行完整Q-K计算，无法享受稀疏加速，构成计算瓶颈。
- **α参数的敏感性**：聚焦比例α需人工调优（实验显示0.5最优），对不同数据集或任务可能需要重新调整。
- **仅验证于SR任务**：论文主要在图像超分辨率上验证，PFA在其他低层视觉任务（去噪、去模糊）或高层视觉/NLP任务上的泛化能力尚待探索（作者已在结论中提及此方向）。
- **固定窗口策略**：当前采用固定32×32窗口，未考虑图像内容自适应调整窗口大小的可能性。

## 研究启发与可借鉴点
1. **跨层信息传递的注意力继承范式**：将上层输出作为下层的先验指导信号（此处为注意力图），是一种通用的"由粗到精"设计思路，可迁移至其他视觉Transformer任务。
2. **稀疏计算与CUDA Kernel联合优化**：论文专门开发了高效的SMM CUDA内核来加速稀疏矩阵运算，证明在算法创新的同时底层算子优化对实际推理速度至关重要，值得借鉴。
3. **动态计算资源分配策略**：按层递减的聚焦比例设计（K^1=N, K^l=αK^{l-1}）实现了"浅层保信息、深层做聚焦"的资源分配理念，可启发其他需要多级处理的模型设计。
4. **注意力可视化辅助分析**：Fig.3展示了不同注意力机制在18层的分布对比，直观证明了PFA的聚焦效果，这种可视化分析方法值得在后续工作中复用。

## 关键术语表
**Progressive Focused Attention (PFA)**：一种跨层注意力继承机制，通过Hadamard积将相邻层的注意力图相连，逐级聚焦重要token并过滤无关token。
**Sparse Matrix Multiplication (SMM)**：稀疏矩阵乘法操作，仅对索引矩阵中值为1的位置执行矩阵乘，实现按需计算以节省算力。
**Focus Ratio (α)**：控制每层保留token数量的衰减比例（K^l = α·K^{l-1}），决定注意力聚焦的激进程度。
**Shifted Window**：偏移窗口策略，通过将窗口在相邻层间偏移一半步长来实现跨窗口信息交互。
**LePE (Local Embedding Position Encoding)**：一种位置编码方案，在窗口注意力中为每个query位置注入局部邻域的位置信息。
**Top-k Sparse Attention**：仅保留每行注意力权重最大的k个值、其余置零的稀疏化策略。
